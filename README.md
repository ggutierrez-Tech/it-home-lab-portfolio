# PowerShell System Report
## Project Objective

This project creates a PowerShell script that collects useful Windows system information for IT troubleshooting.

## Lab Environment

- Windows 11 Enterprise virtual machine
- PowerShell
- GitHub
- VirtualBox or VMware

## Skills Demonstrated

- PowerShell scripting
- Windows administration
- System information collection
- Basic troubleshooting
- Technical documentation

## Information Collected

- Computer name
- Windows version
- IPv4 address
- Disk information
- Running processes
